## How I use Git carefully
- I write a clear, descriptive commit message for every commit that explains what changed and why.
- I run git status and git diff before staging to make sure only intended changes are included.
- I use .gitignore to keep secrets, logs, and temporary files out of the repository.
- I create a separate branch for each feature or improvement and merge it through a pull request.
